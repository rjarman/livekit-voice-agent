# v3.7.0 - IAM, Security & Communication Enhancements
<Badge title="cloud" date="April 20, 2025" space= {16}/>


Original Release Date: April 20, 2025  
Release Name: IAM, Security & Communication Enhancements  
This release includes major upgrades in identity management, user handling, security features, and email configuration. Below is a summary of what's new:

---

## Security Enhancements

- MFA (Multi-Factor Authentication) configuration enabled for projects and users via IAM (login, profile).  
- reCAPTCHA integrated for Signup, Forgot Password, and Activation pages (cloud frontend).  

---

## User Management

- Advanced **user filtering** for quicker access.  
- Enhanced **user details view** with:  
  - Basic info display  
  - Password reset  
  - MFA enable/disable  
  - Assign roles and permissions directly from the user profile  
- Device-wise **access log** per user.  
- **User activity history** for audit and tracking.  

## Roles & Permissions

- Add and manage **roles**.  
- Assign **permissions** to roles.  
- View role details and **filter the permission list**.  

## Email Management

- Add and list **mail server configurations**.  
- Manage **email templates**: add, edit, filter, clone, and view.  
- Send **test emails**.  
- Simplified configuration management.  

## People Management

- Invite users to the **platform**.  
- View and manage the list of **invited users**.
