# v3.7.1 - Multi-Tool AI Chat & Backend Enhancements
<Badge title="cloud" date="August 28, 2025" space = {16} />


This release brings significant improvements to UILM, new functionality in AI and platform modules, as well as multiple fixes for stability and usability.

---

## New Features
### UILM Timeline

- Introduced **Get API** for retrieving timeline data.  
- Added **Show Key Timeline** view to highlight critical entries.  
- Enabled **Save Timeline** capability for persisting updates.  

### AI

- Conversations from bots now display the **source of information**.  

### Project Settings

- Users can now **remove repository access** directly from project settings.  
- Introduced **search filters** for faster repository navigation.  

### Deploy & Observe

- Repositories can now be deployed to **custom domains**.  

---

## Enhancements
- Refactored UILM frontend components with improved consistency and performance.

## Fixes
---
# UILM

- Resolved **import/export** issues.

- Addressed multiple **frontend refactoring** bugs.  

# General

- Improved overall **frontend stability** across modules.
