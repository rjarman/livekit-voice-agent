# v3.7.3 - UILM Export History Enhancements

<Badge title="cloud" date="September 10, 2025" />
## Release Name: UILM Export History Enhancements
This release extends the UILM module with new export history capabilities, providing users with improved visibility, access, and control over their export records.

---

## UILM – Export History
- Introduced an export history list view to review all export records.
- Enabled file download directly from export history entries.
- Added search and filtering options, supporting both text queries and date range filters.
- Implemented pagination for efficient navigation across extensive export history lists.
