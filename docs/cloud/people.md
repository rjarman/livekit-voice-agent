# People

## Overview

Through **People**, Blocks Cloud allows users to share projects with others. When a user navigates to **People** via the menu, they will see a list of individuals who have access to that specific project.

After creating a project, the creator is automatically added to the **People** list.

## Invite a User

Users can invite others to access their project. To do this:

1. Click the **Invite People** button in the top-right corner.
2. Add the email addresses of the people you want to invite in the modal.
3. Click **Send**.
   
![People](/img/People1.png "Invite People")

The invited users will receive an invitation email. By confirming through this email, they will gain access to the project.

![People](/img/People2.png "Invitation Email")

## Revoke a User's Access

To revoke an invited person’s access to a project, click the **Revoke Access** button.

> ⚠️ For the project owner, this button is disabled.

Clicking the button will open a confirmation modal. After confirming, the person will lose access to the project.

## Resend Invitation

If an invited person does not accept the invitation or cannot find the email, you can **resend the invitation**:

* Click the **email icon** next to the person’s name to resend the invitation email.
