# Localization Extension  

<CopyPageButton inidividual= {true}/>

An integral part of the Blocks Language ecosystem is its Language browser extension, engineered 
specifically for translators to manage localization effortlessly from the browser in a What-You-See-Is-What-You-Get (WYSIWYG) environment.  

Developers and admins can perform real-time in-browser edits using the Language browser 
extension, instantly locating and updating text while viewing changes live, without tedious copy-paste routines. For large-scale rollouts, such as rebranding or feature overhauls, the team can apply bulk adjustments to multiple keys simultaneously through the main Language app, saving hours or even days of manual work. Additionally, secure authentication ensures that user access and authorization are tightly controlled, so translations are updated only by trusted team members.  


## Set Up Configuration  

After configuring your desired language, keys, and module, go to Blocks Construct.  
 → This page allows you to instantly modify or change languages.  

**Install the Extension**

1. Go to Chrome Web Store.  
2. Search for SELISE Blocks Assistant  (not the legacy one).  
3. Add this extension to your browser.  

**Sign In to the Extension**

1. Go back to Construct (for example, the Login Page).  
2. Open the browser extension.  
3. Sign in with the same email address that you use for Blocks Cloud.  

**Select Your Project**
From the upper-left corner, select your project.  

**Select Environment**
From the upper-right corner, select the environment you want to work with.  
Toggle Key/Value Mode  
Use the toggle button to switch between Value Mode  or Key Mode. 
 → Let’s keep it in Value Mode. 
   
## View Suggested Keys  

1. Select any sentence or line and right -click.  
2. Click on View Suggested Keys  — it will open selected keys in the side panel with 
details.  
 → It will show the module and the keys.  

## Edit and Translate Values  
Click on Edit Values. Now you have multiple options:  

**Option 1:**  Change the default language value, click Save , and see the change on the UI.  

**Option 2:**  Click on Edit Values  and change the default language value. Then click on Auto-Fill to translate all languages. If you want to go back to the previous translated version, click Revert , then Save  to see the change on the UI.  

**Option 3:**  Click on Edit Values  and change the default language value. Then click on the icon beside each individual language field  to translate languages one by one. If you want to go back to the previous translated version, click Revert , then Save  to see the change on the UI.
