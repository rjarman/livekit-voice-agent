# Usages

## Overview

**Usage metrics** provide detailed insights into how your services are being utilized. By analyzing these metrics, you can monitor service performance, identify bottlenecks, optimize resource allocation, and make informed decisions about scaling and improvements.

These metrics are especially useful for tracking trends over time, understanding which services are most frequently used, and detecting unusual activity that may require investigation.

![Usage](/img/Usage1.png "Usage Metrics")

## Key Features

* **Service Metrics:** View usage statistics for core services such as Authentication, IAM, Storage, and MFA.
* **Filter the Metrics:** You can filter the metrics based on time ranges.
* **Ask AI:** Get information on the usage data from an interactive AI chatbot.


## Viewing Usage Metrics

1. Navigate to **Usages** from the left navigation menu.
2. Review key statistics, including request counts, errors, and average response times.

:::tip 
Use the trend charts to identify peak usage hours and plan scaling or optimizations accordingly.
:::
